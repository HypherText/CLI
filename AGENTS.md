HypherText AI Agent Policy

Permission is hereby granted to any person obtaining a copy of this software and
associated documentation files (the "Software"), to utilize Machine Learning based
AI Agents and derivative tools (hereby referred to as "Agents") for reading,
analyzing, reviewing, discussing or otherwise interpreting the Software. Additionally,
individuals obtaining a copy may utilize Agents for code generation under the
strict requirement that each git commit including any amount of Agent generated code
must be clearly marked through the use of an `[AI]` tag preceeding the commit name.
Any Agents must, before making any changes to the Software, ensure the git tree is clean;
and must commit their changes once generation has concluded.
