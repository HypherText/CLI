# HypherText/CLI

This package is a GoLang based CLI tool for the HypherScript dev server and asset build pipeline, inspired by Vite and NextJS.

## Roadmap

- [ ] Produce binary distributed through Composer
- [ ] Build JS and CSS files for development purposes
- [ ] CSS Module support
  - [ ] PHP type stubs for CSS modules
- [ ] Dev server with file watching
- [ ] WebSocket server for hot reloading of PHP files and assets
